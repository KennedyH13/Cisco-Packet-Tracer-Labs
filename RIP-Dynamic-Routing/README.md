# RIP Dynamic Routing Lab

## Project Overview
This project was completed using Cisco Packet Tracer for my Networks and Telecommunications course at the University of the Incarnate Word.

The purpose of this lab was to configure Routing Information Protocol version 2 (RIPv2) on multiple routers to allow devices on different networks to communicate.

## Network Topology
The network consists of:
- 3 Cisco 1941 routers
- 2 Cisco 2960 switches
- 4 PCs

## Configuration
- Assigned IPv4 addresses, subnet masks, and default gateways to PCs.
- Configured router interfaces to connect multiple networks.
- Enabled RIPv2 on all three routers.
- Advertised directly connected networks using RIP.
- Used `show ip route rip` to examine routes learned by the routers.

## Testing and Troubleshooting
- Used ping commands to test communication between devices.
- Verified connectivity between PCs on different networks after configuring RIP.
- Troubleshot routing configurations when routes did not initially appear.

## Skills Demonstrated
- Cisco Packet Tracer
- IPv4 addressing
- Router configuration
- RIPv2 dynamic routing
- Network troubleshooting
- Connectivity testing
